# Credits and source provenance

- **NFS5 Essentials V2 and the original gameplay fixes:** **ND4SPD Racer**. The bundled `NFS5 Essentials readme.txt` explicitly permits redistribution of that mod provided the original author receives credit.
- **NFS5 Enhanced:** iArtorias and the project's contributors.
- **Porsche 911 GT2, 911 GT3, 928 GTS and 959 add-on assets:** official Need for Speed: Porsche Unleashed add-on content; these are not original Enhanced models.

Source archives used for the 102-file data selection:

- `Unzip to NFS5 installation directory.zip` from the NFS5 Essentials V2 collection.
- `Addon Cars.zip` included alongside the NFS5 Essentials V2 materials.

The `docs/ESSENTIALS_V2_MANIFEST.csv` maps every output path to its source archive member, size and SHA-256. Duplicate add-on textures were deliberately sourced from the main Essentials pack, retaining the texture variants selected by its author.


Original reference: https://www.nfs-cars.com/need-for-speed-porsche-unleashed/3/files/view/11514/
